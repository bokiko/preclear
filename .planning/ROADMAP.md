## Standing Rules For Every Phase

- **Hard-rule actions need bokiko's word in the conversation:** the visibility flip, any history rewrite, any deletion, and any multi-run paid spend. No autonomous run, script or subagent performs them or defaults them.
- **Evidence integrity:** historical folders under `tests/evidence/` are never edited. A rerun adds a new dated folder. Measurement happens on original files before sanitizing, and only leak-gated copies are filed.
- **The skill is frozen:** `SKILL.md`, `references/` and `tests/fixtures/` change only to fix a defect a rerun exposes, and `SKILL.md` stays at or under 12,000 bytes.
- **Commits:** authored solely by bokiko with no AI attribution trailers. Every commit passes the scan hooks.
- **Verdicts:** the harness prints facts. Acceptance is claimed only after Codex review in a visible Herdr tab.
- **Privacy:** this file and every planning artifact use repo-relative paths and refer to the owner only as bokiko, because `.planning/` is public with the repository.
