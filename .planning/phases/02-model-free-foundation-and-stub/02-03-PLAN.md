Write pc_measure.py (EVID-01). It reads original files as bytes, so no newline translation happens, and it never writes.

- Constants: SECTIONS as an ordered tuple of (heading text, cap): Identity and state 800, Boundaries and blockers 600, Next action 500, Resume reading 600, Evidence and working changes 1000, Do not redo 596; FILE_CAP 4096. These are the plain-file checkpoint schema of SKILL.md; a test reads the table from SKILL.md and compares.
- measure_bytes(data) splits with re.split on the bytes pattern for a line start before "## " using the multiline flag, so each piece begins at a heading line and runs to the byte before the next heading; the first piece, when it does not begin with "## ", is the preamble. The heading text is the first line of a piece without the leading "## " and without a trailing carriage return, decoded as UTF-8 with replacement for display only. Each piece's byte length (heading line, its newline and body, nothing stripped) is its size. The result holds total (len of data), the SHA-256 hex of data, a list of (name, size, cap or None) in file order with rows named (preamble) for a leading non-heading piece and (other) for a heading outside SECTIONS (cap None), and the list of expected headings that are absent. Duplicate headings are reported as separate rows.
- measure_file(path) opens the file once in binary mode, reads all bytes, closes, and calls measure_bytes on that one buffer (EVID-01 concurrency); it opens nothing else.
